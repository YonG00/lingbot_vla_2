# stack_bowls_two 第二次放碗样本筛选 V1

独立实验分支 experiment/stack_bowls_sample_weighting；仅做离线标注，没有改训练权重或启动训练。

## 定位与规则

每轨迹两次抓取-放置，通过同臂闭爪后首次松爪匹配；两次释放按时间排序，默认只选第二次。必须恰好两次，且对应抓取已有抬升代理确认，异常轨迹拒绝而不把第一次当第二次。参考位置为示范松爪时TCP位置中位数；不使用固定世界高度，不声称已知碗的位置或接触状态。

- 放置对准：从末段接近起点向前最多4秒，最早不超过该次抓取的抬升确认帧。包含持碗运输末段、姿态和位置调整；这里是上下文窗口，不宣称每帧都在精确瞄准。
- 末段接近：松爪前2秒，距释放参考位置8–11厘米的最后候选帧作起点。沿该段示范实际位移方向下降，与世界向下夹角≤45°，高度降低≥4厘米；相对该路径轴横向偏离≤2厘米，至少70%增量向前（容许2毫米反向）；保持闭爪≤0.2。允许斜向下降，避免误删示范。
- 停稳：进入释放参考位置1厘米内、仍闭爪，连续至少2帧（15FPS约0.13秒）。
- 松爪：开度从≤0.2到≥0.95，TCP偏移≤1.5厘米。
- 撤离：松爪后3秒内保持打开，上撤≥3厘米；只选到初始撤离确认，不包含完整回位。

示范专家place_actor的预放置距离为0.09米，放置后上撤0.09米。数值轨迹显示末段有约4厘米横向位移，因此不能套抓碗时的垂直圆柱阈值。以上为运动学代理，不等于真实无碰撞证明；没有物体位姿/接触力，无法根据它判定是否磕碰碗沿。

## 自动扫描结果与使用

50条轨迹15609帧，100次放置配对；第二次50段通过当前规则，选3743帧（23.98%）。阶段帧数：对准1707、接近371、停稳386、松爪550、初始撤离729。全部为自动筛选结果，尚未对新放置片段做视频边界抽检；50/50是规则覆盖率，不是分类准确率。
