# stack_bowls_two 窄版目标样本 V2

本轮只重新筛选，未改训练/采样/损失参数，未启动训练。当前分支 experiment/stack_bowls_sample_weighting，保留V1便于对照。

## 用户意图与规则

用户更正：不是全阶段约70%都强调；第二碗在接近下层碗前要谨慎，抓碗要关注起始距离较远的示范，并加强远距离定位。

1. 先选远起始抓取：每次已通过抓取时序代理的事件，以该臂在轨迹frame0的TCP到该次示范闭爪TCP中位点的水平距离≥25厘米为条件。100次中20次，来自19条轨迹。按抓取事件判断，不将同轨迹中另一段较近抓取自动纳入。没有使用真实碗中心位姿；第二次抓取的“起始”也明确采用frame0，未改称抓取动作实际开始时刻。
2. 远距离定位：仅在上述事件的上方对准前最多2秒内，夹爪开度≥0.95，距闭爪参考点水平5–20厘米；0.2秒邻域内距离减少≥2毫米，或接近轴相对后续抓取方向的误差减少≥2度。要求同一连续开爪段，排除长时间静止；不包含原整段aim窗口。方向误差只观察接近轴，不声称包含完整夹爪滚转角。
3. 远示范抓取核心：保留已识别的align/descend/settle/close，沿用原抓取规则；不是整个示范。
4. 第二次放置：先通过原第二放置时序代理确认，然后只取末段接近、停稳之前，TCP比示范释放参考点高3–8厘米的帧。不选长距离运输、原放置aim、松爪、撤离；允许沿示范斜向路径下降。这个高度是末端相对释放姿态的代理，不等于碗底到下层碗口的真实净空，不能据此宣称不会碰撞。
